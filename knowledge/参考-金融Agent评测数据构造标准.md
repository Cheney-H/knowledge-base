# 参考-金融Agent评测数据构造标准

**一句话结论**：金融 Agent 评测集要造"真实业务问题、客观唯一解、非一次检索可命中、需多步推理计算"的题；每道题交付 instruction/rubric/oracle/solution/evidence 五件套，靠"写死业务口径 + ≥15 条二元检查点 + 强模型冷跑均值<80%"三道闸把住质量。

## 背景 / 问题
自造金融领域 Agent 评估集（对标 Finance Agent Benchmark V2、FrontierFinance、BigFinanceBench），测 AI 能否用公网/EDGAR/金融数据 API 检索并推理算出结果。核心难点是别让复杂 Agent 题退化成简单 RAG 题。

## 结论 / 做法

### 四条核心原则
- **真实**：任务来自真实业务需求，严禁合成数据（指令与材料都必须真实）。
- **客观唯一**：有客观、唯一（或可判定范围）的答案。
- **非 RAG**：不能靠公网一次检索直接命中。
- **数字化**：可在电脑上用可访问 API 完成；不接受内部私有/外部不可访问资源。

### 每道题五件套交付物
| 交付物 | 文件 | 说明 |
|---|---|---|
| 需求指令 | `instruction.md` | 简洁口语化业务指令，客观唯一解 |
| 检查点 | `rubric.json` | 一系列是否类（二元）断言，全通过为满分 |
| 满分答案 | `oracle_answer.md` | 通过全部 rubric 的可交付答案 |
| 解题思路 | `solution_approach/**` | 详细步骤；建模题保留完整公式 + xlsx |
| 证据材料 | `evidence/**` | 依赖的真实材料，含来源链接与原文件 |

### 任务类型体系（须覆盖 GICS 11 板块，均匀分布）
- **投研与市场分析**：标的筛选 / 公司基本面 / 市场与股价 / 业绩与预期 / 宏观行业 / 信息监测汇总（后者须≥2 维交叉，禁单期单源单点）。
- **财报与披露分析**：跨期比较 / 口径调整与非经常项 / 治理与薪酬 / 一般定量（须产出派生指标）。
- **估值建模与交易**：可比公司 / 财务建模情景预测 / 先例交易并购 / 投资回报与偿债。
- **财务运营与核算**（DA 重点）：结算 / 核算凭证 / 审计 / 对账，规则口径容差写死、逐笔可追溯。

### 交付物关键标准
- **指令**：客观唯一解；**不写解题步骤**但**必须写死业务口径**——判据"删掉这句是否会出现两个都合理却数字不同的答案，会则必须写"；要素齐全（任务/主体/期间/指标/口径）；≥50 字词、从业者需≥2h、材料≥5 个；中:英=1:2、单一任务类型≤总量 20%；中英题各贴合国内/北美市场、禁纯翻译。
- **检查点**：二元表述、原子性（一条一面）、完备自包含（自带主体/期间/单位、首现给全称）、无重叠、核心结论权重更高；**金融一般≥15 条**，计算链中间量单设检查点。
- **数值书写**：金额带符号单位 `$22,213.50 million`；负数用括号 `(3.47%)`；百分比 2 位；百分点写 `percentage points`；基点 `1,715 basis points (bps)`；倍数 `11.47x`；仅披露本身有尾差时用 `approximately`。
- **证据**：来源链接+原文件，真实禁合成；渠道 = 公网(Tavily) / EDGAR(sec-api.io) / 金融数据(Tiingo)；禁内部不可访问资源。

### 难度门槛（先验 + 后验）
- **先验**：题≥50 字词、evidence≥5、专家预估≥2h。
- **后验**：Claude-opus-5 / gpt-5.6 / gemini-3.8 / qwen3.8 等强模型跑 4 次，**mean<80% 且无单次>90**，且强弱模型有区分度（不刻意刁钻）。详见 [[方法-Benchmark后验难度验收]]。

### 红线（常见问题）
- 指令：难度过低 / 无唯一答案 / 口径缺失 / 时间漂移（如"最近一个财年"随时间变）。
- 检查点：<15 条 / 数值无容差 / 结论不唯一。
- 证据：材料缺失或链接失效 / 需付费登录 / 证据链断（数字无法定位到披露文件+位置）。
- 不适合的题：依赖实时盘中行情；依赖 Bloomberg/CapIQ 等付费终端独有数据；出现 `latest`/`current` 却无期间锚定；一次全文检索即命中的单点题。

### 三方向评分法（跨方向参考）
- **Research**：正向 `+12/+6/+3`、负向 `-5/-10/-20`、门控 `0`；归一化加权分 + 通过率；难度三轴（概念广度/逻辑嵌套深度/探索度）。
- **KA**：权重仅 `6/8/10`（6=事实核对、8=单文件计算、10=跨文件综合）；一题下所有 criterion 全过才得分。
- **DA**：检查点按百分比赋权（2%–10%）；主观项 LLM Judge、客观项代码判定；主观累计≤25%；设 mis 项（故意植错口径，得分应落 0.2–0.85）校验分辨力。

## 反例 / 边界（何时不适用）
- **中:英=1:2、单类型≤20%** 是金融方向整个评测集层面的分布要求，不约束单道题（报告类 Research 任务不受此约束）。
- 纯抽取/事实核查型评测不适用"非 RAG + 多步推理"的加难逻辑。
