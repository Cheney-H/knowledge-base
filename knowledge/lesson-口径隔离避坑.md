# lesson-口径隔离避坑

**一句话结论**：市场研究/数据类结论最隐蔽的错误是"口径混用"——不同口径的数字长得都像"占比/规模"，混排或相减就会得出错误结论；每个数字必须显式标口径，且供给端≠需求端。

## 背景 / 问题
从一份报告取数做综合结论时，容易把口径不同的指标当同类比较、加总或排序。

## 结论 / 做法（典型混用陷阱）
- **端口混用**：网页端"月访问量"（访问次数）≠ 移动端"MAU"（活跃用户数）≠ 硬件"渗透率"（AI 用户中占比）≠ "TGI"（相对基准的偏好倍数×100）。四者不可加总/互换/同表排序。同一产品在不同口径下排名可以完全不同（如某产品网页端第3、移动端第1）。
- **供需混用（最易错）**：供给端"智能体数量占比"≠ 需求端"使用热度占比"。把"某类供给占比高"当成"该类需求旺盛"是硬错误；正确解读常是**供给过剩、使用遇冷**，反而暴露能力短板。
- **单位陷阱**：两个比例相减得到的是"百分点 / percentage points"，不是"%"；环比"+7.7 个百分点"写成"+7.7%"即错。

## 反例 / 边界（何时不适用）
- 同口径、同时点、同分母的数字才可直接比较/相减。
- 报告本身用词不严谨（如把环比"个百分点"写成"%"）时，如实标注原文口径，不要盲目照搬其错误表述。
