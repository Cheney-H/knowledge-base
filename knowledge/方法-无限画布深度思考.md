# 方法-无限画布深度思考（Excalidraw）

**一句话结论**：无限画布的价值不在"画图"而在"思考可视化"——它几乎零成本地支持"想到哪写到哪"，把发散的想法用关系图谱梳理成线性化输出；关键是**收集与梳理彻底分离**。

## 背景 / 问题
需要深度思考的问题有三个特征：牵扯私人的多种现实因素博弈、需要长期积累才能达成、方法高度私人（他人方案未必适用）。这类思考量巨大，容易让人产生畏难心理、用打扫/打游戏/发呆来逃避。

## 结论 / 做法

### 收集与梳理分离
- **收集阶段**：通勤/走路时最容易有灵感，随手写进备忘录；到电脑前一股脑粘进画布，粘完立即关掉——**完全不整理、不分话题**。只有所有想法被平等对待，重要的想法才能在梳理后凸显。
- **梳理阶段**：另开时间，把堆叠的想法拖动排布。工具支持"想到哪是哪"，让思路梳理几乎零成本，深度思考变成一场开放性游戏。

### 关系图谱法（梳理的四条规则）
1. 没关系的内容放远一点。
2. 有关系的内容放到一起。
3. 找相关内容之间的**底层逻辑**。
4. **解开矛盾/冲突**就能获得解决方案。

### 字号即凸显（可视化规则）
- 初始阶段所有想法用**最小字号**（对应"平等记录"）。
- 放大字号只用于三种情况：①底层逻辑 ②冲突/矛盾 ③被多个想法链接到的节点。
- 原理：人类更容易聚焦群体中的大个体；但只有在"其余都小"时放大才起凸显作用。

## 反例 / 边界（何时不适用）
- "今天吃什么"这类无需深度思考的问题，不必上画布。
- 画布对"连续作画"不友好（默认画完回到箭头，需锁定状态栏）——因为它定位是思考工具而非画图工具，别用错预期。
