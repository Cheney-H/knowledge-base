# 方法-Benchmark后验难度验收

**一句话结论**：知识工作类评测题不靠主观判断难度，靠"冷跑后验"——给强模型只喂题目+原始材料跑多次，均值 <80% 且无单次 >90% 才算合格；聚在 ~96% 就是直接抽取题，必须向多跳计算/口径辨析加难。

## 背景 / 问题
自造评测题时，凭感觉判断"这题挺难"极不可靠。看起来涉及多个子任务、多页数据的题，强模型只要能读到原始 PDF 往往一次全取，区分度为零。

## 结论 / 做法
1. **冷跑**：只给「题目 + 原始材料（PDF）」，**不给** rubric、不给参考答案，独立跑 4 次。
2. **双阈值验收**：按 rubric 打分，`均值归一化分 < 80%` **且** `无单次 > 90%` 才入库。
3. **诊断**：若均值 ~96%、每次都 >90% → 题目被"可直接摘录的事实"主导，偏易。
4. **加难方向**（保持数据锚点不变，只改问法）：
   - 降直接抽取权重，加**多跳计算**（材料没直接给、需两三步算出的量，如占比、倍数、合计）。
   - 加**口径陷阱**（见 [[lesson-口径隔离避坑]]），靠口径辨析负向项拉开分差。
   - 加**需推理的判断题**（评分者更易分歧、模型更易失分）。

## 反例 / 边界（何时不适用）
- 冷跑失分若源于**工具不可用**（如模型没联网/没数据库权限做二源交叉），那不是"难度"，别据此判过难——真实评测里模型有工具会更高分。
- 纯抽取型/事实核查型评测（本就考"能否准确取数"）不适用此加难逻辑。

## 重要边界：可判定性-难度两难（数据齐备型报告题不可达 <80%）

CONS-002（华泰二合游戏研报改造）实证：对**数据齐备、逻辑自洽**的咨询报告题，「均值<80% 且无单次>90%」在**保持 rubric 可判定的前提下不可达**。四轮加难全部验证失效（冷跑均值始终 ≈96%）：

1. **移除脚手架**（删处置结论/正确裁决、把源报告移出输入）——强模型自行发现全部口径矛盾。
2. **口径判断类加难**（制造"须识别并裁决的口径冲突"，如单值口径来源内部自相矛盾判不可考）——识别并裁决口径矛盾恰是当前前沿强模型的**可靠能力，不是区分点**。
3. **残缺闭合类加难**（分母残缺、需按系数折算重合池）——只要折算规则可从材料推定，模型即正确折算。
4. **执行难度类加难**（脏明细逐行自清洗：币种/口径/去重/期间/锚点/品类 6–8 条分散规则）——**会写代码的 agent 完整一致地逐条应用，零遗漏**。纯算术/清洗执行难度对 code-capable agent 无效。

**根因（核心可复用判断）**：**可判定 ⇒ 正确答案可从材料推定 ⇒ 前沿强模型即推得出并执行**。要 rubric 干净可判，正确答案就必须能从材料推定；能推定，强模型就解得出。难度若只来自"判断"或"照规则执行"，都落在强模型可靠能力区内，形不成区分度。

**跳出两难的方向**（都不是再调 References）：
- 真正的难度来源须是**材料内不可推定**的：需外部一手检索/建模才能闭合、故意欠定需自设情景做敏感性、需推翻表面自洽数据的反直觉裁决——但这些又会牺牲可判定性，是另一重取舍。
- 或**改评分为连续分档**（敏感性深度/论证严谨度/证据交叉充分度），用强模型 vs 中弱模型的**分差**做区分，放弃"均值<80%"绝对门槛。
- 或**如实标注入库**为"数据齐备型口径纪律基线题"（中低难度、不追求高区分度）——CONS-002 最终即取此路。

**实操提示**：动手加难前先判断题目类型。若属"数据齐备、逻辑可解"型，直接走连续分档或如实标注，别在移除脚手架/造口径陷阱上反复空跑（CONS-002 耗了四轮冷跑才确认不可达）。

## 第三次实证 + 提前止损（南方电网中长期战略，2026-10-07）

单一企密内部战略文件（南方电网，34 页）改造的 Research 题，第三次复现同一天花板。rubric 已加难至 40 条、向多跳计算(CAGR/增幅)、口径辨析(线损 6.3 vs 6.15、销售收入≠营业收入、停电 8.76 是目标非现状、小时 vs 分钟，均 +12)、结构辨析(+12) 倾斜，并设 gate 负向(口径漂移/编造 −20)。冷跑 FG1 仍 **index1 93.9%、index2 95%，零负向触发**，仅失 A9(增幅基准)与 C3(内部一致性未显式断言)。

**关键差异：这次没再空跑四轮**。FG1 单点 93.9% > 90% 已击穿验收线，叠加前两次(QM ≈96.3%、CONS-002 ≈96%)同型结论，判定题型为"数据齐备、逻辑可解"后**立即止损、如实标注入库**，未补跑 N=4——即上面"实操提示"的直接应用。三份报告题(QM/CONS-002/南方电网)现已同型，该天花板可视为对**数据/逻辑齐备型报告题**的稳定规律，不必每题四轮验证。

> 教训升级：当题目的**教学点本身就是口径/单位辨析**时，题面必须点名陷阱，这些点名项即退化为"照单核对"的检查项——注定高分。此类题从设计之初就该定位为纪律基线题或走连续分档，不要指望压到 <80%。
