# 方法-单源件评测的引用维度

**一句话结论**：当评测题的源材料是**单一企密/内部文件、无公开第二数据源**可交叉时，不要硬凑外部双源，用「内部页码/图表可追溯 + 内部交叉引用一致性校验」替代"外部双源交叉"作为引用/来源质量维度。

## 背景 / 问题
通用的 Research 评测构造标准要求"关键数值须用公开可核验的第二来源交叉"（见 [[参考-金融Agent评测数据构造标准]] 的 no-single-paid-source 原则）。但有些高价值源本身就是**单一的内部/企密文件**（如企业中长期战略终稿），市面上根本不存在第二个可公开核验的数据源。此时硬套"外部双源"要么逼着补造 URL（破坏可信度），要么判全体引用项不达标（冤枉）。

## 结论 / 做法
把引用维度（C 类检查点）从"外部双源"改造为两条**内部**可核验标准：

1. **逐条页码/图表可追溯**：每条事实类结论必须标到源文件的具体页码或图表编号（如"第 3 页""图 1"）。注意印刷页码可能与 PDF 物理页有固定偏移（南方电网件为 印刷页 = 物理页 − 1），校准后再标。
2. **内部交叉引用一致性校验**：同一指标在文件内多处出现时，检查是否自洽，分三种结论——
   - **一致**：如全网停电时间 8.76 小时在"主要指标表"与"举措表"两处对齐 → 加分项。
   - **不同口径但不矛盾**：如综合线损率"2010 预计 6.3%"与"第一步目标 6.15%"是不同时点/性质，并存不构成矛盾 → 须显式说明二者为何不矛盾，而非判错。
   - **真矛盾**：同口径同指标两处打架 → 才是要暴露的问题。

## 配套：口径时点必须钉死
单源件尤其容易混"现状实际 / 某年预计 / 目标值"。每个数字标清时点口径（"2009 年底实际"vs"2010 预计"vs"第一步目标"）。报告**未直接披露**的量（如某指标的现状点值）必须显式写"报告未披露"，若用异口径反推须标"异口径折算、非报告直接披露"，不得臆造——这类"臆造现状点值当报告数据"应设为 gate 负向。详见 [[lesson-口径隔离避坑]]。

## 边界
- 仅适用于确实不存在公开第二源的单一信源件；只要有公开一手源，仍优先外部双源。
- 内部一致性校验替代的是"交叉验证"动作，不替代"锚定时间口径、不引入后续真实数据"的硬约束（口径漂移仍是 gate 负向）。
