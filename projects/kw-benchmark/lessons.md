# 知识工作评测集 · 关键经验与踩坑

## 关键经验
- **难度靠后验，不靠直觉**：给强模型只喂题目+原始材料冷跑多次，均值 <80% 且无单次 >90% 才算合格；聚在 ~96% 就是可直接抽取的题，须向多跳计算/口径辨析加难。
- **每个数字必须显式标口径**：市场研究/数据类题目里，端口、供需端、百分点等口径混用是最隐蔽的错。
- **金融方向自成一套构造标准**：真实/客观唯一解/非 RAG/多步推理四原则，五件套交付，≥15 条二元检查点、数值书写规范、多源证据链（EDGAR/Tiingo/Tavily）。中英 1:2、单类型≤20% 是集合层面要求，不约束单题。

## 踩过的坑
- 自造题凭感觉判"这题挺难"，强模型能读到原始 PDF 往往一次全取，区分度为零。
- 不同口径的数字长得都像"占比/规模"，混排、相减、排序就会得出错误结论。

## 报告类 PPTX 评测题构造（CONS-002 二合游戏，2026-09-30）
- **一份报告只造一道综合大题**，不拆多题；报告类 Research 任务用简体中文，不受金融的中英 1:2 约束。
- **区分度来源=报告天然口径矛盾**：券商研报内并存多套自相矛盾口径（中性单值 vs 空间区间、IAP vs 流水、Sensor Tower vs AppMagic、人民币 vs 美元、两套中国份额口径），直接改造成陷阱检查点，避免直接抽取即高分。
- **负向条数≥10%（吸取 CONS-001 教训）**：CONS-001 负向仅 8.5%(按条数)偏低，CONS-002 提到 13.6%(6/44)。
- **付费源不作唯一出处**：Sensor Tower/AppMagic 精确数值配公开一手/权威第三方交叉；检索不到就如实标注"未找到公开一手来源"，不补造 URL。`verify_evidence.py` 自检快照存在+日期未越锚点+原文摘录命中。
- **PPTX 目视评分需 LibreOffice**：`pptx→PDF→PNG` 路径依赖 soffice；未装则 P-02/P-04 目视子项跑不通，须先 `brew install --cask libreoffice`。

## CONS-002 加难四轮全败：可判定性-难度两难（2026-09-30 定稿）
- CONS-002 冷跑均值始终 ≈96%，四轮加难（移除脚手架 / 口径判断 / 残缺闭合折算 / 脏明细执行清洗）全部验证失效，`均值<80% 且无单次>90%` 对该题**不可达**。
- 根因：**可判定 ⇒ 答案可从材料推定 ⇒ 前沿强模型可解**。识别口径矛盾、按规则折算、逐行清洗脏数据都是 code-capable 强模型的可靠能力，非区分点。
- 第四轮探针实证：脏明细 + 6–7 条分散清洗规则，强模型用 Python 读全表全脚注、逐条零遗漏应用，还主动点出双重计入陷阱——执行难度也挡不住。
- **决策**：用户拍板"如实标注入库"，CONS-002 定位为**数据齐备型口径纪律基线题**（中低难度，不追求高区分度）；task_card §7 记全四轮结论。
- **可复用判断**：动手加难前先判题型；"数据齐备、逻辑可解"型直接走连续分档或如实标注，别在移除脚手架/造口径陷阱上空跑。详见 [[方法-Benchmark后验难度验收]] 新增"可判定性-难度两难"边界段。

## 南方电网中长期战略：单源件题 + 天花板第三次实证（2026-10-07）
- **单一企密内部件**（南方电网中长期发展战略终稿，34 页，无公开第二源）改造的 Research 题，五件套齐备，落在 `OfficeData/南方电网中长期战略_task/`。
- **引用维度用内部可追溯替代外部双源**：逐条标页码/图表 + 内部交叉引用一致性校验（8.76 小时跨指标表/举措表一致；线损 6.3% vs 6.15% 不同口径不矛盾）。提炼为复利页 [[方法-单源件评测的引用维度]]。
- **难度天花板第三次复现**：rubric 加难至 40 条（多跳 CAGR/增幅 + 口径辨析停电现状/小时vs分钟/线损双口径/销售收入≠营业收入 均 +12 + gate 负向），冷跑 FG1 仍 index1 93.9%/index2 95%、零负向触发，仅失 A9/C3。
- **提前止损**：FG1 单点 >90% 即判型"数据齐备型"，不再空跑 N=4，直接如实标注入库为「口径纪律/时点锚点基线题」——即《方法-Benchmark后验难度验收》"实操提示"的落地。详见 `南方电网中长期战略_task/冷跑验收记录.md`。
- **工程留痕**：本环境后台 general-purpose 子代理稳定失败（stream watchdog @600s），冷跑须走前台 + 文本抽取源；图片型图表（图 1 收入结构）文本层缺失须手工转录；印刷页码 = PDF 物理页 − 1。
