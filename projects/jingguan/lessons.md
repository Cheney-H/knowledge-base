# 竞品观察室组 2027 规划 · 经验教训

## L1 数据供应（文心方向）从战略主线降为机会副线
- **预训练**：量打不过大搜（约 10x），且预训练量本非模型能力关键 → 退出拼量。
- **CoT 诱导/蒸馏**：自研失败、破解即便成功成本也高于外采、安全部已介入接管 → 放弃自研。
- **办公环境 Benchmark**：仅 3 道成功题、批量未证、题源未知、卡在评估团队系统、不一定算 MEG 战功、褚高斯有顾虑 → 不 All in，降为 gated 实验。
- 提炼为通用判据见 [[方法-跑通到押注的三道闸]]。

## L2 技术做成 ≠ 战功：立方向前先对齐上级"战功口径"
- Benchmark 即便做成，从 MEG 整体看不一定是战功，褚高斯有顾虑。
- **教训**：方向要对齐奖励它的人；OKR 向上对齐对象的"战功认定"必须先问清，别埋头做完才发现不被记功。
- **行动**：1-on-1 摸清顾虑（归属/命脉/投产比/竞合/机会成本）与战功口径，再定数据线定位。

## L3 Benchmark 三道闸 + 止损
- 题源闸 / 批量可行性闸 / 命脉自主闸，任一长期过不去即收；小人力（建议安康 + 0.5）、限一个季度。见 [[方法-跑通到押注的三道闸]]。

## L4 三条线同一个病：基础设施/协作方的战功困境
- 数据供应、内容质量评估供数、抓取中台（内容建设 ~10%）全都"稳但随百度 APP 大盘衰落、果实被下游摘、战功难归属"。
- 解法：守成榨成本当养人田（抓取中台今年 GBI/智能爬虫/数字员工已初步落地），出彩赌注押命脉自主线（竞观/竞Mate）；三线不必都出彩。提炼见 [[lesson-基础设施型团队的战功困境]]。

## L5 技术团队挂战略下的承接法：杠杆承接 + 翻译表
- 技术团队与战略上级 OKR 语言不同（技术产能力/数据/工具，上级要洞见/研究/投资），承接难、果实别人摘。
- 解法：不做任务承接，做杠杆承接 + 价值链上移——把技术折算成上级货币（洞见/数据准确/投资/提效），KR 主语换成上级货币，并主动摆"翻译表"对齐考核口径。
- 2027 落地＝三座桥：洞见引擎(O1) / 数据底座(O2-KR1) / 投资弹药(O2-KR3) + 提效(O3)。提炼见 [[方法-技术团队杠杆承接上级OKR]]。
