# Cheney 的第二大脑 · 关键决策

> 记录「做了什么决定 + 为什么」。换环境后最值钱的部分。

## D1：采用三层架构（项目层 / 复利层 / 记账层）
- **决定**：`projects/` 记全，`knowledge/` 提炼通用经验，`log.md` 记账
- **为什么**：融合第二大脑（项目层求全）与 llm-wiki（复利层求通 + 记账留痕）；两层职责分离，不重不漏
- **日期**：2026-09-29
- **状态**：现行

## D2：范围仅限工作/项目，不建 raw/、不涵盖生活 Areas
- **决定**：只做工作/项目，故意不建外部资料囤积层
- **为什么**：YAGNI；来源就是对话与项目本身，无需囤外部文章
- **日期**：2026-09-29
- **状态**：现行

## D3：Obsidian 定位为"人类只读导航层"
- **决定**：引入 Obsidian 但只用于看双链/图谱/搜索，写入仍走 Agent + Git
- **为什么**：双链与图谱对人类消费复利有价值；写入交给 AI 可避免方言/维护负担
- **日期**：2026-09-29
- **状态**：现行

## D4：schema 双份（AGENTS.md 主 + CLAUDE.md 指向）
- **决定**：操作约定写在 AGENTS.md，CLAUDE.md 一行指向它
- **为什么**：工具无关，Codex 等任意 Agent 可随时接管；单一主文件避免两份漂移
- **日期**：2026-09-29
- **状态**：现行

## D5：运行节奏用组合式（随手记 + 节点深沉淀 + 定期体检）
- **决定**：Ingest 随手 / Distill 里程碑 / Lint 每两周
- **为什么**：贴合真实工作节奏，降负担同时保质量、防腐烂
- **日期**：2026-09-29
- **状态**：现行
